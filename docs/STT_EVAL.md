# In-app speech-to-text (AI model) — desktop check, NOT a phone

What was tested: Gemma 4 E4B (`gemma-4-E4B-it.litertlm`, the same file the app imports) transcribing Bengali audio through LiteRT-LM's audio input (`Content.AudioBytes` = a 16 kHz mono 16-bit WAV file; the app sends exactly this).
Clips: the first 6 test items of the Hugging Face dataset `kawshikbuet17/bengali-telecom-customer-care-speech-v2` (CC BY 4.0). **These are synthetic (text-to-speech) recordings, clean and read at an even pace — easier than a real person in a real room.** Real-voice, accent, noise and phone-microphone results are NOT measured here.
CER = character error rate against the reference text. Timing is desktop CPU; a phone will be slower (not measured).
