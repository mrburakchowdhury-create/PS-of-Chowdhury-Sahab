# S24 Ultra ডিভাইস-টেস্ট চেকলিস্ট

**নিয়ম:** যা এখানে ফাঁকা, সেটা এখনো পরীক্ষা হয়নি। কোনো সংখ্যা অন্য ফোন বা ডেস্কটপ থেকে এনে বসাবেন না। প্রতিটির পাশে পাস/ফেল ও আসল সংখ্যা লিখুন।

## ক. ইনস্টল ও লক
- [ ] APK ইনস্টল হয়; অ্যাপ খুললে লক/সেটআপ দেখায় (ফলাফল: )
- [ ] ভুল PIN ৩ বারের পর অপেক্ষা শুরু; ডেটা মোছে না
- [ ] বায়োমেট্রিক দিয়ে খোলে; পরে ফোনে নতুন আঙুলের ছাপ যোগ করলে বায়োমেট্রিক বন্ধ হয়ে PIN চায়
- [ ] Recent-apps/স্ক্রিনশটে কনটেন্ট দেখা যায় না; ৩০ সে. পেছনে থাকলে লক হয়
- [ ] airplane mode-এ সব চলে; Settings → Apps → অ্যাপ → Permissions-এ শুধু Microphone (চাইলে) আছে, ইন্টারনেট নেই

## খ. ফাইল ও মডেল
- [ ] PDF import → Vault-এ এনক্রিপ্টেড (Device File Explorer-এ plaintext নেই)
- [ ] মডেল (Gemma 4 E4B) import: কপি শেষে "✅ অফিসিয়াল ফাইলের সঙ্গে মিলেছে" দেখায় (ফাইল ≈ 3.66 GB; কপির সময়: )
- [ ] মডেল লোড সময়: ____ সে.; প্রথম টোকেন: ____ সে.; গতি: ____ token/s; peak RAM: ____ MB (`adb shell dumpsys meminfo app.personal.banglaai`)

## গ. PDF ও অনুবাদ
- [ ] ১০ পৃষ্ঠার টেক্সট PDF: লেখা বের হয়, পৃষ্ঠা-নম্বর মেলে
- [ ] স্ক্যান PDF: UNREADABLE দেখায় → OCR (বাংলা/আরবি/উর্দু/হিন্দি/ইংরেজি) → নির্ভুলতা (নিজের নমুনায়): 
- [ ] অনুবাদ: pause → অ্যাপ বন্ধ → খুলে resume; সম্পন্ন পৃষ্ঠা আবার হয় না
- [ ] ৫০০ পৃষ্ঠার টেক্সট PDF; ১০০০ পৃষ্ঠার PDF: সময় ____, peak RAM ____, তাপ/ব্যাটারি ____ ; low-memory-তে কী হয়: 
- [ ] coverage রিপোর্টের সংখ্যা (মোট/সম্পন্ন/ব্যর্থ/পড়া যায়নি) বাস্তবের সঙ্গে মেলে
- [ ] এক্সপোর্ট TXT/DOCX/PDF: বাংলা যুক্তাক্ষর ঠিক, আরবি/উর্দু ডান-থেকে-বাঁ ঠিক, Word-এ DOCX খোলে (**DOCX এখনো কোনো Word-এ খোলা হয়নি**)

## ঘ. কোড
- [ ] ছবির কোড (Python/JS) → OCR → indentation ও চিহ্ন ঠিক কি না; সন্দেহজনক অংশ চিহ্নিত
- [ ] ব্যাখ্যা বাংলায়; diff আসল লাইনের সঙ্গে মেলে; কোড কখনো চলেনি

## ঙ. ভয়েস
- [ ] ফোনে অফলাইন বাংলা TTS voice আছে? নেই হলে অ্যাপ নির্দেশ দেয় (নাম: )
- [ ] পড়া: play/pause/resume/গতি/আগে-পরে; পড়ার অবস্থান অ্যাপ বন্ধের পরও থাকে
- [ ] 🎤 চেপে বলুন: বাংলা on-device চেনা আছে কি; "২০ নম্বর পৃষ্ঠা পড়ো" সঠিক বোঝে; অ্যাপের নিজের কণ্ঠ নির্দেশ হিসেবে ধরে না
- [ ] স্ক্রিন বন্ধ করলে পড়া চলে; নোটিফিকেশনে কোনো ফাইলের নাম/লেখা নেই; লক-স্ক্রিনে নোটিফিকেশন দেখা যায় না; থামা/চালু/বন্ধ কাজ করে; ইয়ারফোনের প্লে/পজ বাটন কাজ করে; নোটিফিকেশন থেকে নতুন কিছু শুরু করা যায় না

## চ. ব্যাকআপ
- [ ] ব্যাকআপ তৈরি → অ্যাপ মুছে আবার ইনস্টল → ব্যাকআপ থেকে ফেরান → ফাইল ও অনুবাদ ফিরেছে
- [ ] ভুল পাসফ্রেজে ফেরানো ব্যর্থ হয়

## জ. ভয়েস কল ও ছবি
- [ ] কল শুরু → "শুনছি" → প্রশ্ন বললে উত্তর শোনা যায়, তারপর আবার "শুনছি"
- [ ] বলার সময় ছবিতে চাপলে থামে; "কল শেষ" বললে শেষ হয়; অ্যাপ ব্যাকগ্রাউন্ডে গেলে শেষ হয়
- [ ] নিজের ছবি বসানো/মোছা; লোগো ফিরে আসে
- [ ] অফলাইন বাংলা ভয়েস না থাকলে বার্তা আসে (বন্ধ করে দেখুন)
- [ ] ছবি: জুম, ঘোরান, কাটুন, OCR, "পৃষ্ঠার লেখা" সংরক্ষণ
- [ ] অংশে চাপ → বোঝান / প্রশ্ন; ব্যাপক খোঁজ চালু করে উত্তর
