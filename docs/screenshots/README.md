# স্ক্রিন-রেন্ডার (ফোনের স্ক্রিনশট নয়)
আসল অ্যাপ-কোড থেকে Robolectric native graphics দিয়ে বিল্ড-মেশিনে রেন্ডার (S24 Ultra-র আকার ≈ 412×915 dp)। ফোনে ফন্ট, রঙ, সিস্টেম বার ভিন্ন দেখাতে পারে।
আবার বানাতে: `./gradlew testDebugUnitTest --tests '*ScreenshotTest*'` → `app/build/screenshots`।
1 খোলার পর্দা · 2 প্রথম PIN সেটআপ · 3 হোম (ব্যানার, লেখার আকার, ভয়েস) · 4 ভয়েস নির্দেশ বোঝার উদাহরণ · 5 হোমের নিচের অংশ (পরিভাষা, শব্দভান্ডার, স্টোরেজ, ব্যাকআপ) · 6 লক-স্ক্রিন

7 সহকারী (মডেল না থাকলে বার্তা) · 8 ফোন-পরীক্ষা (ছবিতে ফোনের নাম/RAM পরীক্ষার পরিবেশের, আসল ফোনের নয়)
